- 🧩 **Own large features end to end** across a multi-client monorepo serving enterprise Shopify and commercetools storefronts.
- 🏭 **Supagas** — Built the **B2B commerce layer** for the replatform onto headless Next.js + Shopify B2B: company-level accounts, customer-specific pricing, approval & ordering flows, and order automation via **Shopify Flow**.

- 👥 **Team leadership** — peer review & merge authority on production work, technical interviews for engineering hires, and onboarding new developers.
- 📈 Integrated **GA4 & Google Tag Manager** for conversion/event tracking; applied **SEO, WCAG accessibility & Core Web Vitals** best practices throughout.
